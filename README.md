# test-quiz-cinq-blessures-de-l-ame
Ce test a pour but de d'identifier les blessures dont la Leaman est porteuse, ainsi que les comportements qu'elle adopte le plus souvent afin de proposer un accompagnement psychologique et spirituel adéquat. "Bien-aimée, je souhaite que tu prospères à tous égards et sois en bonne santé, comme prospère l'état de ton âme." (3 Jean 1:2)
